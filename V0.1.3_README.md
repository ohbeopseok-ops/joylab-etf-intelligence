# JoyLab ETF Intelligence V0.1.3

## Goal

- Direct stock market value
- ETF indirect look-through exposure
- Cluster exposure
- KIS live quote integration
- Read-only / paper mode only

## Install

Copy files into existing repository.

Create live portfolio config:

```powershell
copy config\portfolio.example.json config\portfolio.json
notepad config\portfolio.json
```

Enter actual quantities only.

Example:

```json
{
  "positions": [
    {"symbol":"005930","name":"삼성전자","quantity":3,"type":"stock"},
    {"symbol":"069500","name":"KODEX200","quantity":1,"type":"etf"}
  ],
  "clusters": {
    "semiconductor":["005930","000660"]
  }
}
```

Run:

```powershell
python scripts/portfolio_exposure_report.py
```

Regression:

```powershell
pytest tests/gold_cases -q
```

## Architecture

Direct:
quantity × KIS current price

Indirect:
ETF market value × component weight

True exposure:
direct + indirect

Cluster:
sum(True exposure of cluster symbols) / total visible portfolio value
