# V0.2 TASK-001 — AI Power ETF Overlap

TASK-001 adds a read-only, normalized multi-ETF overlap and look-through engine.
It does not add any order or trading API.

## Formula and coverage

Weighted overlap uses the raw disclosed source weights:

`Overlap(A,B) = Σ min(weight_A_i, weight_B_i)`

Weights are not rescaled to 100%. Therefore an ETF diagonal is its captured
holding-weight sum, not an assumed 100%. Missing or unsupported constituent data
produces an explicit status and a null overlap value, never a silent 0%.

Look-through and cluster weights use the sum of the explicitly supplied ETF
market values as denominator. An unavailable ETF stays in that denominator and
is listed as a data gap, preventing known exposure from being overstated.

The concentration HHI is the sum of squared underlying percentage weights on a
0–10,000 scale. The disclosed coverage, Top1, Top5 and HHI preserve the source
weights and may reflect small source-rounding differences around 100%.

The default `power_equipment` membership is the 12 non-cash holdings confirmed
on the official KODEX AI전력핵심설비 product page on 2026-08-25. It is a
transparent TASK-001 taxonomy, not a claim that every possible power-equipment
company is included. Cluster membership remains configuration-driven.

## Private position input

The report runner requires an explicit local JSON file:

```json
{
  "positions": [
    {"etf_symbol": "487240", "market_value": 1000000}
  ]
}
```

`config/ai_power_positions.example.json` is a synthetic equal-value example,
not an account snapshot and not a production allocation assumption.

Run with private input and output paths that will not be committed:

```powershell
.\.venv\Scripts\python.exe scripts\ai_power_overlap_report.py `
  --positions C:\private\ai_power_positions.json `
  --output C:\private\ai_power_report.json
```

The output contains the load status, weighted overlap matrix, common holdings,
Core8 look-through, Semiconductor and Power Equipment clusters, and a
concentration summary. ETF market values are never guessed or equally weighted.
